# RU Tech — оценка IT-компаний

Дашборд оценки публичных российских IT-компаний: Позитив, Астра, Базис, Аренадата, Диасофт, Софтлайн.

## Что на странице

- **Карточки котировок** — цена, изменение за день, капитализация / EV, доходность за 1М, 3М, с начала года, 1 год, выбранный мультипликатор.
- **Рейтинг оценки** — EV/EBITDAC или P/NIC на выбранный год (2025–2028 или NTM) с медианой выборки.
- **Оценка и рост** — мультипликатор против CAGR EBITDAC/NIC, размер точки — капитализация.
- **Тепловая таблица мультипликаторов** — все годы, цвет = отклонение от медианы столбца, сортировка по клику.
- **Сравнение финпоказателей** — выручка, EBITDAC, NIC, рентабельность, рост г/г (млрд руб или индекс 2025 = 100) и сводка CAGR / средних рентабельностей 2025–2030.
- **История** — цена (ребазированная, с IMOEX) и NTM-мультипликатор по историческим ценам.

## Данные

| Файл | Что внутри | Как обновляется |
|---|---|---|
| `data/fundamentals.json` | прогнозы (млн руб), кол-во акций, чистый долг, источники прогнозов | из Excel-базы скриптом `scripts/build_fundamentals.py` |
| `data/prices.json` | дневные цены закрытия с MOEX (TQBR) + IMOEX, текущая цена | GitHub Actions, `scripts/update_quotes.py` |
| `data/status.json` | лог последнего запуска | GitHub Actions |

Все мультипликаторы считаются в браузере из этих файлов: при каждом обновлении цены пересчитываются автоматически.

## Расписание обновления котировок

Рабочие дни, МСК: 11:00, 14:00, 17:00, 19:00. Внутридневная точка дня заменяется официальной ценой закрытия при следующем запуске. Ручной запуск: Actions → **Update MOEX quotes** → Run workflow (`full = true` — перезагрузить всю историю).

## Обновление прогнозов

1. Пересчитать и сохранить Excel-базу (скрипт читает сохранённые значения ячеек).
2. Загрузить её в `base/software_comps.xlsx` (Add file → Upload files) — workflow пересоберёт `data/fundamentals.json` и сверит мультипликаторы с блоком C4:J9.
   Либо локально: `python3 scripts/build_fundamentals.py путь/к/файлу.xlsx --check` и закоммитить `data/fundamentals.json`.

Если в Excel меняется расположение строк или добавляется компания — поправить таблицу `COMPANIES` в `scripts/build_fundamentals.py` (там же список `FLAGS` для пометок ⚠).
